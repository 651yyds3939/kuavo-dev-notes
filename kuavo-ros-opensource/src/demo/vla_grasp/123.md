下面是当前左爪抓瓶盖、调平、旋转和循环相关的完整调参表。建议保留此表作为后续实机标定记录。

**一、初始落点参数**

这三个参数负责左爪接近瓶盖、下降和闭合前的初始位置，不负责旋转过程中的漂移。

| 参数 | 当前值 | 单位 | 控制效果 | 现象与调整方向 | 建议步长 |
|---|---:|---:|---|---|---:|
| `_left_tcp_extra_x_m` | `-0.010` | m | 前后位置，`+X` 向机器人前方 | 夹爪太靠前→减小；太靠后→增大 | `0.002～0.005` |
| `_left_tcp_extra_y_m` | `-0.035` | m | 左右位置，`+Y` 向机器人左侧 | 夹爪太靠左→减小；太靠右→增大 | `0.002～0.005` |
| `_left_tcp_extra_z_m` | `0.045` | m | 初始高度，`+Z` 向上 | 夹爪太高→减小；太低→增大 | `0.002～0.005` |
| `_left_cap_yaw_decouple_extra` | `true` | bool | 防止 X/Y 微调同时改变夹爪朝向 | 建议始终保持 `true` | 不调 |

常用换算：

```text
0.001m = 1mm
0.002m = 2mm
0.005m = 5mm
```

只调初始落点的指令：

```bash
cd ~/kuavo-ros-opensource

python3 src/demo/vla_grasp/bimanual_unscrew.py \
  _left_cap_twist_cycles:=0 \
  _left_tcp_extra_x_m:=-0.010 \
  _left_tcp_extra_y_m:=-0.035 \
  _left_tcp_extra_z_m:=0.045
```

**二、旋转中心参数**

`pivot_ee` 表示夹持旋转中心相对于 `zarm_l7_end_effector` 的局部坐标。它不是机器人 `base_link` 世界坐标。

| 参数 | 当前值 | 坐标系 | 控制效果 | 调节建议 |
|---|---:|---|---|---|
| `_left_cap_twist_pivot_ee_m` | `[0.018,0.010,-0.0525]` | 末端局部坐标 | 决定夹爪上的哪个点作为旋转中心 | 当前效果已较好，建议固定 |
| `pivot.x` | `0.018` | EE 局部 X | 当前主要影响切换到旋转阶段时的初始对齐 | 不建议继续用于修正动态漂移 |
| `pivot.y` | `0.010` | EE 局部 Y | 横向偏心量 | 当前已验证，建议固定 |
| `pivot.z` | `-0.0525` | EE 局部 Z | EE 到有效夹持中心的长度分量 | 小于约 `-0.045` 时存在 IK 临界问题 |

你当前的稳定值：

```text
_left_cap_twist_pivot_ee_m:="[0.018,0.010,-0.0525]"
```

注意：

- 修改 `pivot` 可能同时改变闭爪前静态调平的初始位置。
- `pivot` 是几何旋转中心，不应再用于处理剩余的世界坐标线性漂移。
- 剩余上下、左右漂移使用后面的动态 XYZ 补偿。

**三、旋转前姿态参数**

这些参数负责左爪抓住瓶盖前的静态姿态。

| 参数 | 当前值 | 单位 | 控制效果 | 现象与调整方向 | 建议步长 |
|---|---:|---:|---|---|---:|
| `_left_cap_twist_pitch_offset_deg` | `-4.0` | deg | 旋转前夹爪静态调平 | 尖端太高→更负；尖端太低→减少负值 | `0.25～0.5°` |
| `_left_cap_twist_prelevel_sec` | `2.0` | s | 静态调平总时间 | 动作太快/抖→增大；太慢→减小 | `0.5s` |
| `_left_cap_twist_prelevel_step_deg` | `0.25` | deg | 静态调平每个 IK 路点角度 | 抖动明显→减小；通常不需要改 | `0.05～0.1°` |
| `_left_cap_twist_level_axis` | `local_x` | 枚举 | 静态及动态调平使用的末端局部轴 | 已实机确认，保持 `local_x` | 不调 |
| `_left_cap_roll_extra_rad` | `-0.325` | rad | 修改目标姿态中的夹爪局部滚转；由 IK 分配到多个关节，不等同于关节6或7 | `0.01～0.02rad` |
| `_left_cap_pitch_extra_rad` | `0.0` | rad | 接近、悬停和触顶阶段的基础 pitch 微调 | 先保持 `0`；确需改变整段接近姿态时每次 `0.01～0.02rad` |
| `_left_cap_base_roll_extra_rad` | `0.0` | rad | 基座姿态 roll 微调，可能明显影响 IK | 一般保持 `0` |
| `_left_cap_yaw_offset_rad` | `0.0` | rad | 左爪接近瓶盖时的朝向偏置 | 左右朝向有系统误差时小步调整 `0.01rad` |
| `_left_cap_approach_pitch_rad` | `-1.57079633` | rad | 左爪垂直接近的基础 pitch（约 `-90°`） | 已验证，通常不调 |
| `_left_cap_wrist5_bias_rad` | `0.0` | rad | 触顶后直接给左臂关节5增加固定偏置，主调小臂/末端整体水平 | 先用 `±0.05rad` 判方向，再以 `0.01～0.02rad` 精调 |
| `_left_cap_wrist6_bias_rad` | `0.0` | rad | 触顶后直接给左臂关节6增加固定偏置，主要修正夹爪前高后低 | 先用 `±0.05rad` 判方向，再以 `0.01～0.02rad` 精调 |
| `_left_level_bias_contact_only` | `true` | bool | 限制 wrist5/6 偏置仅在触顶后生效，避免破坏接近 IK | 建议保持 `true` |

静态调平单独测试：

```bash
python3 src/demo/vla_grasp/bimanual_unscrew.py \
  _left_cap_twist_cycles:=0 \
  _left_cap_twist_pitch_offset_deg:=-4.0 \
  _left_cap_twist_prelevel_sec:=2.0 \
  _left_cap_twist_prelevel_step_deg:=0.25 \
  _left_cap_twist_level_axis:=local_x
```

判断原则：

```text
pitch_offset 和 wrist5/6 的实机正负方向会随当前姿态变化，必须先做正负小角度对照。
wrist5/6 是直接关节偏置，可能移动夹爪 TCP；pitch_offset 是固定 pivot 的 IK 姿态调整。
调 wrist5/6 时先把 pitch_offset 和 pitch_comp 设为 0，避免多个调平量叠加。
```

关节5/6独立测试：

```bash
python3 src/demo/vla_grasp/bimanual_unscrew.py \
  _left_cap_twist_cycles:=0 \
  _left_cap_twist_pitch_offset_deg:=0.0 \
  _left_cap_twist_pitch_comp_deg_per_deg:=0.0 \
  _left_cap_wrist5_bias_rad:=0.0 \
  _left_cap_wrist6_bias_rad:=0.05 \
  _left_level_bias_contact_only:=true
```

如果关节6的 `+0.05rad` 让前高后低更严重，只把它改成 `-0.05rad` 做对照。

**四、旋转中姿态补偿**

这个参数只负责旋转过程中夹爪是否保持水平，不负责夹爪整体的位置。

| 参数 | 当前值 | 单位 | 控制效果 | 现象与调整方向 | 建议步长 |
|---|---:|---:|---|---|---:|
| `_left_cap_twist_pitch_comp_deg_per_deg` | `-0.50` | deg/deg | 每旋转 `1°` 增加的动态俯仰补偿 | 旋转时尖端逐渐抬高→更负；逐渐压低→减少负值 | `0.05` |
| `_left_cap_twist_pitch_comp_frame` | `world_horizontal` | 枚举 | 将调平轴固定在世界水平面，避免随 yaw 转动 | 已验证，保持不变 | 不调 |
| `_left_cap_twist_level_axis` | `local_x` | 枚举 | 夹爪前后调平轴 | 已验证，保持不变 | 不调 |

当前动态补偿：

```text
旋转10°：累计动态pitch = 10 × -0.50° = -5°
旋转15°：累计动态pitch = 15 × -0.50° = -7.5°
旋转20°：累计动态pitch = 20 × -0.50° = -10°
```

终端测试：

```bash
python3 src/demo/vla_grasp/bimanual_unscrew.py \
  _left_cap_twist_cycles:=1 \
  _left_cap_twist_cycle_deg:=-10.0 \
  _left_cap_twist_pitch_comp_deg_per_deg:=-0.50 \
  _left_cap_twist_level_axis:=local_x \
  _left_cap_twist_pitch_comp_frame:=world_horizontal
```

**五、旋转中 XYZ 位置补偿**

这三个参数专门负责旋转过程中夹持点的前后、左右和上下漂移。

补偿量按照旋转绝对累计角度计算：

```text
目标位置补偿 = abs(累计旋转角度) × 每度补偿
```

回正到 `0°` 时会自动归零，不会在每轮永久累积。

| 参数 | 当前值 | 单位 | 世界坐标方向 | 现象与调整方向 | 建议步长 |
|---|---:|---:|---|---|---:|
| `_left_cap_twist_x_comp_per_deg_m` | `0.0` | m/deg | `+X` 向机器人前方 | 逐渐向后→增加正值；逐渐向前→使用负值 | `0.0001～0.0002` |
| `_left_cap_twist_y_comp_per_deg_m` | `0.0015` | m/deg | `+Y` 向机器人左侧 | 仍向右偏→增大；开始向左偏→减小 | `0.0001～0.0002` |
| `_left_cap_twist_z_comp_per_deg_m` | `-0.00185` | m/deg | `+Z` 向上，负值向下 | 仍逐渐上升→更负；逐渐下降→减少负值 | `0.0001～0.0002` |

当前每旋转 `10°` 的累计位置补偿：

| 方向 | 每度补偿 | 10°累计 |
|---|---:|---:|
| X | `0mm/deg` | `0mm` |
| Y | `+1.5mm/deg` | 向左 `15mm` |
| Z | `-1.85mm/deg` | 向下 `18.5mm` |

完整 XYZ 补偿测试：

```bash
python3 src/demo/vla_grasp/bimanual_unscrew.py \
  _left_cap_twist_cycles:=1 \
  _left_cap_twist_cycle_deg:=-10.0 \
  _left_cap_twist_reclose:=false \
  _left_cap_twist_x_comp_per_deg_m:=0.0 \
  _left_cap_twist_y_comp_per_deg_m:=0.0015 \
  _left_cap_twist_z_comp_per_deg_m:=-0.00185
```

启动日志应显示：

```text
XYZ补偿=(0.00,1.50,-1.85)mm/deg
```

调节规则：

```text
旋转时仍向右：
Y 0.0015 → 0.0016 → 0.0017

旋转时开始向左：
Y 0.0015 → 0.0014 → 0.0013

旋转时仍向上：
Z -0.00185 → -0.00195 → -0.00205

旋转时逐渐向下：
Z -0.00185 → -0.00175 → -0.00165
```

**六、旋转轨迹参数**

这些参数控制旋转角度、速度、路点密度和 IK 连续性。

| 参数 | 当前值 | 单位 | 作用 | 调节建议 |
|---|---:|---:|---|---|
| `_left_cap_twist_mode` | `in_place_ik` | 枚举 | 固定有效 TCP，使用连续 IK 旋转 | 保持不变 |
| `_left_cap_twist_cycle_deg` | `-10.0` | deg | 每轮有效旋转角度 | 可测试 `-15`，暂不建议直接用 `-20` |
| `_left_cap_twist_cycles` | `1` | 次 | 有效旋转轮数 | 测试用 `1～3`，完整任务按角度计算 |
| `_left_cap_twist_step_deg` | `0.5` | deg | 用户期望的旋转步长 | 保持不变 |
| `_left_cap_twist_cartesian_max_step_deg` | `0.25` | deg | 实际笛卡尔轨迹最大角度间隔 | 当前较平滑，保持不变 |
| `_left_cap_twist_cartesian_deg_per_sec` | `2.0` | deg/s | 旋转速度 | 抖动→降到 `1.5`；稳定后可试 `2.5` |
| `_left_cap_twist_joint_jump_deg` | `8.0` | deg | 单路点最大允许关节跳变 | 安全阈值，不建议放宽 |
| `_left_cap_twist_direct_l7_enable` | `false` | bool | `false` 使用固定 TCP 连续 IK | 保持 `false` |
| `_left_cap_twist_seed_l7_enable` | `true` | bool | 使用 L7 预旋 seed 引导连续 IK | 保持 `true` |
| `_left_cap_twist_fk_xy_tolerance_m` | `0.0025` | m | 模型 FK 的 XY 允许误差 | 安全检查，通常不调 |
| `_left_cap_twist_fk_z_tolerance_m` | `0.0015` | m | 模型 FK 的 Z 允许误差 | 安全检查，通常不调 |

单次 `15°` 测试：

```bash
python3 src/demo/vla_grasp/bimanual_unscrew.py \
  _left_cap_twist_cycles:=1 \
  _left_cap_twist_cycle_deg:=-15.0 \
  _left_cap_twist_reclose:=false
```

注意：动态补偿按角度累计，所以从 `10°` 改为 `15°` 后，Y/Z/pitch 补偿也会增加到原来的 `1.5` 倍。

**七、松爪回正与循环参数**

用于实现棘轮式动作：

```text
闭合 → 旋转 → 打开 → 回正 → 再闭合
```

| 参数 | 当前默认值 | 作用 | 调节建议 |
|---|---:|---|---|
| `_left_cap_twist_reclose` | `false` | 是否在每轮后松爪、回正并重新闭合 | 多轮拧盖设为 `true` |
| `_left_cap_twist_release_pos` | `60.0` | 每轮回正前左爪松开位置 | 建议循环测试使用 `35.0` |
| `_left_cap_twist_cycles` | `1` | 有效旋转次数 | 总角度÷每轮角度 |
| `_left_cap_twist_cycle_deg` | `-10.0` | 每轮有效拧盖角度 | 当前已验证 |

角度与循环次数：

| 每轮角度 | 完成720°需要 |
|---:|---:|
| `-10°` | `72`轮 |
| `-15°` | `48`轮 |
| `-20°` | `36`轮 |

三轮循环验证：

```bash
python3 src/demo/vla_grasp/bimanual_unscrew.py \
  _left_cap_twist_cycles:=3 \
  _left_cap_twist_cycle_deg:=-10.0 \
  _left_cap_twist_reclose:=true \
  _left_cap_twist_release_pos:=35.0
```

不要第一次直接运行 `72` 轮。建议按照：

```text
1轮 → 3轮 → 10轮 → 完整轮数
```

逐级确认没有累积偏移。

**八、夹爪闭合、触顶与 IK 辅助参数**

文档原先还遗漏了下面这些可调参数。它们不是旋转补偿，但会影响是否能可靠接触、夹紧以及连续求解。

| `_left_contact_preclose_effort` | `0.22` | effort | 半开触顶阶段夹爪力度 | 仅在触顶反馈不稳定时小步调整 |
| `_contact_step_m` | `0.002` | m | 每次下降距离 | 精度不足时减小；搜索太慢时谨慎增大 |
| `_contact_max_steps` | `25` | 次 | 最大下降步数 | 搜索范围不足时增加，但必须结合硬下限 |
| `_contact_effort_threshold` | `0.28` | effort | 判定触顶的 effort 阈值 | 误触发则增大；始终检测不到则减小 |
| `_contact_z_stop_above_m` | `0.003` | m | 相对瓶盖 Z 的软停止参考 | 触顶过早则减小；压得过深则增大 |
| `_contact_z_max_below_cap_m` | `0.006` | m | 允许低于瓶盖推算 Z 的硬下探量 | 安全参数，不建议随意增大 |
| `_left_cap_close_pos` | `98.0` | position | 左爪最终闭合目标 | 已接近安全上限，通常不调 |
| `_left_cap_effort` | `1.0` | effort | 左爪夹瓶盖力度 | 打滑时小步增大，确认不损伤瓶盖和夹爪 |
| `_left_cap_close_min_pos` | `80.0` | position | 闭合验收的最低位置反馈 | 只在验收误判时调整 |
| `_left_cap_close_effort_stop` | `0.50` | effort | 分步闭合时的 effort 停止阈值 | 仅启用 ramp 时有效 |
| `_left_cap_close_ramp_enable` | `false` | bool | 是否分步闭合左爪 | 需要柔和夹紧时设为 `true` |
| `_left_cap_close_ramp_step` | `8.0` | position | 分步闭合的每步增量 | ramp 开启后按需要调整 |
| `_left_cap_close_ramp_sleep_sec` | `0.0` | s | 分步闭合每步后的额外等待 | 控制器反馈不足时才小步增加 |
| `_left_cap_close_wait_sec` | `0.25` | s | 单次夹爪服务调用的短轮询时间 | 通常不调 |
| `_left_cap_close_settle_sec` | `2.5` | s | 每步等待夹爪到位的最长时间 | 经常未到位超时时适当增加 |
| `_left_cap_close_retries` | `4` | 次 | 单步夹爪服务失败重试次数 | 通信稳定时不调 |
| `_left_cap_final_squeeze_enable` | `false` | bool | 闭合后是否执行最终重复加压 | 打滑且确认安全时才启用 |
| `_left_cap_final_squeeze_sec` | `1.0` | s | 每次最终加压持续时间 | 仅 final squeeze 开启时有效 |
| `_left_cap_final_squeeze_passes` | `2` | 次 | 最终加压重复次数 | 仅 final squeeze 开启时有效 |
| `_left_cap_twist_l7_seed_min_deg` | `-38.0` | deg | 连续 IK 中关节7 seed 下限 | 关节安全/连续性参数，通常不调 |
| `_left_cap_twist_l7_seed_max_deg` | `38.0` | deg | 连续 IK 中关节7 seed 上限 | 关节安全/连续性参数，通常不调 |
| `_left_cap_twist_use_contact_yaw` | `true` | bool | 旋转阶段沿用触顶 yaw | 建议保持 `true`，避免夹紧后重新偏航 |
| `_left_cap_twist_face_right_yaw_rad` | `-1.57079633` | rad | `use_contact_yaw=false` 时额外叠加的朝右偏航 | 当前配置不生效，通常不调 |
| `_left_cap_twist_step_sec` | `0.45` | s | 旧式逐步/关节旋转模式的单步时间 | 当前连续 `in_place_ik` 主要由 `cartesian_deg_per_sec` 控速 |

触顶与闭合参数一次只调整一项，并始终保留硬安全下限。姿态、落点已经正确时，不要用这些参数修正旋转漂移。

**推荐总调参顺序**

| 顺序 | 观察目标 | 只调整的参数 |
|---:|---|---|
| 1 | 左爪初始前后对准 | `left_tcp_extra_x_m` |
| 2 | 左爪初始左右对准 | `left_tcp_extra_y_m` |
| 3 | 左爪初始高度合适 | `left_tcp_extra_z_m` |
| 4 | 旋转前静态水平（优先直接关节微调） | `left_cap_wrist6_bias_rad`，必要时再调 `left_cap_wrist5_bias_rad` |
| 5 | 固定 pivot 的旋转前姿态微调 | `pitch_offset_deg`（不要与 wrist5/6 同时改） |
| 6 | 旋转中持续水平 | `pitch_comp_deg_per_deg` |
| 7 | 旋转中不再上下漂移 | `z_comp_per_deg_m` |
| 8 | 旋转中不再左右漂移 | `y_comp_per_deg_m` |
| 9 | 必要时修正前后漂移 | `x_comp_per_deg_m` |
| 10 | 验证触顶与夹紧可靠性 | `contact_*`、`left_cap_close_*` |
| 11 | 验证重复性 | `cycles`、`reclose`、`release_pos` |
| 12 | 最后再尝试增大单轮角度 | `cycle_deg` |

核心原则：一次只改一个参数，初始落点、姿态和动态位置分别观察，不要为了消除位置漂移去改姿态补偿。
